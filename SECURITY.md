# Security Policy

## Supported Versions

Security fixes are prepared for the latest stable WLANScope release.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository. Include the affected
version, reproduction conditions, expected impact, and any proposed remediation. Do not open a
public issue or disclose exploit details before a coordinated fix is available.

Product security boundaries and excluded capabilities are documented in
[docs/security.md](docs/security.md).
